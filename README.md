### 📁 О репозитории
Этот репозиторий является техническим **CDN (Content Delivery Network)** для проекта **tprank**.

Здесь хранятся все статические ресурсы, которые используются на сайте с пранками: изображения, звуковые эффекты и графические элементы интерфейса. Выделение медиафайлов в отдельный репозиторий позволяет обеспечить быструю загрузку контента по прямым ссылкам и поддерживать чистоту кода в основном репозитории.

### 📂 Структура
*   `/banner/` — баннеры и обложки
*   `/logo/` — логотипы и аватарки
*   `/buttons/` — кнопки интерфейса
*   `/*.jpeg`, `/*.webp` — изображения для пранков
*   `/*.mp3` — звуковые эффекты

### 🔗 Прямые ссылки
Все файлы доступны по прямым ссылкам. Например:
`https://tprank.github.io/cdn/svinia.webp`
